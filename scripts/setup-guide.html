Tools and companion installed

One last step.
Enable VidRush in Chrome.

All required tools are ready. Chrome needs you to add the extension yourself once. No commands, accounts, or programming knowledge are needed.

  1. Switch to the Extensions tab

    Setup opened it beside this guide. If you cannot see it, type chrome://extensions in Chrome's address bar.

    Chrome not installed? Get Google Chrome first, then open this guide in Chrome.

  2. Turn on Developer mode

    Use the switch at the top-right of the Extensions page.

  3. Click Load unpacked

    Copy this folder path, paste it into the folder dialog's address bar, press Enter, then click Select Folder.

  4. Pin VidRush and download a video

    Open Chrome's Extensions menu (the puzzle-piece button), pin VidRush, then open a video page and click its icon. Choose a quality and click the blue download button.

Your videos will be saved to {{DOWNLOAD_PATH}}. Keep Chrome open while downloading. The extension has been copied to a permanent folder; you can move or remove the original project folder after activation.

Updating an older VidRush install? If Chrome still loads the extension from the original project folder, remove that old entry before loading the folder shown above. For later updates, reload VidRush on the Extensions page after rerunning Install.cmd.
